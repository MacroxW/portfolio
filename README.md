## Portfolio profesional de Marcos Wendy

Portfolio estático construido con Astro, TypeScript y Tailwind CSS. Presenta experiencia Full Stack, soluciones con IA, arquitectura, cloud, productos propios y proyectos open source.

### Desarrollo

```sh
pnpm install
pnpm dev
pnpm build
```

El sitio se publica en GitHub Pages mediante `.github/workflows/deploy.yml` cuando se actualiza la rama `main`.
